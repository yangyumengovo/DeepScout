> 离线演示语料（示意性技术综述，供 mock 模式使用）

旋转位置编码 RoPE（Rotary Position Embedding）是大模型长上下文扩展中最常用的位置编码方案。它把序列中每个 token 的位置信息编码为复平面上的旋转角度，叠加在 Query 与 Key 向量上，使注意力得分自然地成为相对位置的函数。由于具备相对位置性质，RoPE 在序列长度超出训练范围时的行为比绝对位置编码更可控，因此绝大多数主流开源模型都以其为默认位置编码。

直接外推（直接把推理长度拉到训练长度之外）会让 RoPE 的注意力分布失真，出现「窗口变长、能力不升反降」的现象。围绕这一问题，社区发展出一批外推与内插方法：位置内插（PI）把位置编号按比例缩小回训练区间；NTK-aware 缩放改写 RoPE 的基底，让高频分量保持外推、低频分量内插；YaRN 进一步区分不同频率维度并配合注意力温度修正。这些方法的共同点是不改训练数据、只改位置编码的数学形式，即可用少量长文本微调甚至零微调换取窗口扩展。

在工程实践中，扩展上下文窗口通常是「位置编码外推 + 训练数据配比调整 + 注意力与 KV 显存优化」的组合拳。位置编码解决「模型能否看到更长的序列」，后两者解决「算力与显存是否扛得住更长的序列」。评估某个模型的长上下文能力时，需要同时关注名义窗口长度与有效窗口长度，二者经常存在明显差距，只有经过专门的长文本评测才能区分。
